# /verify-task Workflow

1. Read `PLAN.md`, `TASKS.md`, and the active task's relevant rules/skills.
2. Inspect only files and behavior in scope for that task.
3. Run the smallest relevant checks for success, validation, failure, and security behavior.
4. Report evidence and failures; fix only issues within the task if asked/authorized.
5. Mark the task complete only when all required verification passes.
6. Do not begin a different task.
